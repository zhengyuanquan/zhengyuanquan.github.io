# MLP 参数学习可视化实验台

课程作业：手写多层感知机（MLP）的参数学习过程，并在浏览器中实时可视化。

## 在线体验 / 本地运行

- 本仓库为纯静态页面，无需任何依赖与构建。
- 本地：直接用浏览器打开 `index.html`。
- 在线：把本目录部署到 GitHub Pages 即可访问。

## 功能

- **手写反向传播**：前向传播 → 交叉熵损失 → 链式法则求梯度 → 全批量梯度下降，全部由原生 JS 实现，不调用任何机器学习库。
- **决策边界实时演化**：网格逐点前向推理，背景色显示预测概率，看边界随训练一点点成形。
- **网络结构与权重可视化**：连线粗细/颜色表示权重大小与符号，悬停任意神经元可查看其权重、偏置和当前激活值。
- **训练曲线**：损失（交叉熵）与准确率随 epoch 变化的实时曲线。
- **前向传播探测**：点击平面任意点，查看该点从输入到输出的逐层数值计算明细。
- **我来画数据**：自定义模式下直接在画布上画红/蓝样本点，让网络学习你画的图案。
- **挑战模式**：设定目标准确率（90/95/98%），比拼最少多少轮达成，历史最佳纪录存在浏览器本地。
- **可调超参数**：数据集（同心圆 / 异或 / 双月牙 / 双螺旋 / 自定义）、噪声、隐藏层结构、激活函数（tanh / ReLU / Sigmoid）、学习率、训练速度。空格键快捷开始/暂停。

## 建议玩法

1. 默认「同心圆 + 单隐藏层 6 神经元」，点「开始训练」，观察损失下降、边界合拢。
2. 换「双螺旋」，单层学不会（欠拟合），把隐藏层改成 `8,6` 或 `8,8`、学习率调到 0.3~0.5 再试。
3. 训练中拖动学习率：太大震荡、太小停滞，直观感受 η 的影响。
4. 选「我来画数据」，画个圈或字母让网络学，再打开挑战模式刷纪录。
5. 点击决策平面任意点，对照右侧表格手算一遍前向传播。
